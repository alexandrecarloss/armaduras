# 🌌 Galeria Armaduras de Ouro

Projeto desenvolvido como parte do módulo de JavaScript do curso de **Desenvolvedor Web Full-Stack** do programa **Web Academy (UFAM)**.

O objetivo principal foi criar uma galeria de imagens interativa e acessível, aplicando conceitos de manipulação de DOM, tratamento de eventos e lógica de programação com JavaScript puro (Vanilla JS).



## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica.
- **CSS3**: Estilização avançada, uso de CSS Grid, Flexbox, Animações e Backdrop-filter para efeitos visuais.
- **JavaScript (ES6+)**: Lógica de renderização dinâmica, manipulação de eventos e controle de estado da interface.

## ✨ Funcionalidades

- **Renderização Dinâmica**: As miniaturas das armaduras são geradas automaticamente a partir de um array de objetos no JavaScript.
- **Troca de Imagem**: Ao clicar (ou pressionar Enter) em uma miniatura, a imagem principal, o título e a descrição são atualizados instantaneamente.
- **Efeito Darken/Lighten**: Um botão interativo que altera a luminosidade da imagem principal através de um overlay dinâmico.
- **Design Responsivo**: Interface adaptada para diferentes tamanhos de tela (Desktop, Tablet e Mobile).
- **Acessibilidade**: Implementação de suporte para navegação via teclado.
